# 📌 Detector de Fraude

> Desafio proposto pela Residência Fullstack (Instituto Eldorado), onde era preciso criar uma solução que detectasse possíveis mensagens de golpe

* Funcionalidades
    * Sistema de Pontuação: analisa as mensagens contra um arquivo CSV de palavras suspeitas. A presença desses termos eleva a pontuação de risco e a probabilidade de fraude.
    * Vericicador de Link: examina as URLs fornecidas para validar se correspondem a padrões seguros e confiáveis.
